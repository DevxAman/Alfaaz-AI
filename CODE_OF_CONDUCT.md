# Code of Conduct

## Our Commitment

The ALFAAZ project is committed to maintaining a respectful, professional, and collaborative environment for all contributors and users.

We encourage constructive discussions, responsible contributions, and a welcoming community focused on innovation in Punjabi NLP and AI systems.

---

## Expected Behavior

All contributors are expected to:

- Be respectful and professional
- Use inclusive and constructive language
- Accept feedback gracefully
- Focus on improving the project collaboratively
- Maintain a positive development environment

---

## Unacceptable Behavior

The following behaviors are not tolerated:

- Harassment or abusive language
- Hate speech or discrimination
- Personal attacks or trolling
- Malicious code contributions
- Spam or disruptive behavior

---

## Contribution Standards

Contributors should ensure that:

- Code is clean and maintainable
- Changes are meaningful and documented
- Existing functionality is not intentionally broken
- Contributions align with project objectives

---

## Enforcement

Project maintainers reserve the right to reject or remove contributions that violate this Code of Conduct.

---

## Contact

For concerns or reporting issues, please use GitHub Issues or repository discussion channels.
